# Adam Lite 跳跃方案说明

> 仓库：`pnd_rl_gym`  
> 整理时间：2026-07-24  
> 环境：conda `pnd_jump`  
> **当前推荐部署**：SFU-height @ 4000 → `policy_lstm_sfu_height.pt` + `adam_lite_jump_sfu_height.yaml`  
> 一键 sim2sim：`bash sim2sim_jump_best.sh`

---

## 1. 一句话总结

用 **SFU 双脚跳动捕** 作运动学先验，在 **Isaac Gym** 用 **PPO + LSTM** 学相对参考轨迹的 **残差 PD 动作**，导出 TorchScript 后在 **MuJoCo** 做 sim2sim。

**不追求原地跳**（参考本身会走位）。成功标准：落地姿态、多跳存活、高度/关节跟踪，而不是相对原点 XY。

**当前主线（推荐）：**

```text
Jul14 teacher_ft @3000
    → SFU track FT → Jul23_16-17-14_jump_sfu_track @3600   （稳，落地好）
        → height FT → Jul24_11-41-12_jump_sfu_height @4000 （跳高↑，仍稳）★ 推荐
```

---

## 2. 问题定义与设计动机

### 2.1 要解决什么

Adam Lite（腿部 12 DOF）完成双脚跳跃：下蹲 → 蹬地 → 腾空 → 落地站稳，并尽量贴近参考的高度与姿态。

### 2.2 为什么用 motion tracking + 残差

| 路线 | 问题 |
|------|------|
| 纯运动学回放 | 无接触/惯性补偿，落地易摔 |
| 纯 RL 从零学跳 | 搜索空间大、样本效率低 |
| **参考轨迹 + 残差 RL（本方案）** | 先验给出形态，策略只学动力学修正 |

控制式：

```text
q_des = q_ref + action * action_scale    # action_scale = 0.35
τ     = Kp * (q_des - q) - Kd * dq
```

## 6. 强化学习核心

### 6.1 PPO + LSTM 怎么理解

| 名称 | 角色 |
|------|------|
| **PPO** | 训练算法 |
| **LSTM / ActorCriticRecurrent** | 策略网络（训练+推理） |
| **`policy_lstm_*.pt`** | 导出的 Actor TorchScript |

```text
obs(82) → LSTM(h=128) → MLP[256→128→64] → action(12)
critic：特权 obs(85) → 对称 LSTM+MLP → V(s)
```

### 6.2 观测（Teacher v4 / SFU / height，**82 维**）

| 段 | 维数 | 内容 |
|----|------|------|
| 本体 | 3+3 | 基座角速度、投影重力 |
| 相位 / 朝向 | 2+2 | `sin/cos(phase)`，`sin/cos(yaw_err)` |
| 参考与误差 | 12+12 | 当前 `q_ref`、跟踪误差 |
| 速度 / 动作 | 12+12 | 关节速度、上一动作 |
| 未来参考 | 12+12 | 未来 **+5、+10** 帧 Δq |
| **Actor 合计** | **82** | |
| Critic | +3 线速度 | **85** |

缩放：`ang_vel×0.25`，`dof_vel×0.05`，`action_scale=0.35`。

### 6.3 奖励主项（Teacher 基线）

走路类奖励置零。主跟踪项：`root_pos` / `root_height` / `dof_pos` / `root_yaw` / `root_vel` / `orientation` + 平滑惩罚 + `alive`。

各 FT 变体在此基础上改 scale（见 §8）。

### 6.4 终止 / RSI / DR

- 终止：非足接触过大、pitch/roll 超阈、根高掉出参考过多（SFU）、运动播完、超时  
- RSI：phase-balanced 采样起点，加重 crouch / takeoff / landing  
- DR：摩擦、质量扰动、观测噪声；SFU 另加轻度 landing push + 1-step action delay

### 6.5 一次控制步数据流（简图）

```text
参考表[t] + 仿真状态 → obs_actor[82]
        → Actor LSTM+MLP → a[12]
        → q_des = q_ref + 0.35·a → PD → τ → 仿真
        → reward / done →（训练）PPO
```

更细的张量布局与导出逻辑见历史实现：`adam_lite_jump_env.py`、`motion_loader.py`、`deploy_mujoco_jump.py`。

### 11.2 关键问题与解法

**Q1：纯回放参考为什么不够？**  
A：缺接触与惯性补偿，落地即摔。→ 残差 RL：`q_des = q_ref + 0.35·a`。

**Q2：要不要主推 BC / TWIST student？**  
A：BC 可作 warm-start，student 去未来帧便于部署，但 sim2sim 未超过 82 维 teacher。→ 保留脚本作实验，**主线不用**。

**Q3：v5 加历史/短未来为何失败？**  
A：观测维数↑、分布偏移大，从 Jul14 warm-start 后 MuJoCo 泛化差；消融证明不是“少了历史/未来某一项”就能救。→ **保持 82 维 +5/+10**。

**Q4：落地易摔、摔倒后相位还在跑？**  
A：终止太松 → 学到“摔着播完”。→ SFU：更紧 pitch/roll，增加 `root_z` 相对参考过低即 reset；加强 orientation / yaw / foot_slip。

**Q5：robust 强扰动适得其反？**  
A：扰动过大，策略变保守、跳高掉。→ SFU 只用**轻度** landing push + 1-step delay。

**Q6：为何不追求原地跳？**  
A：参考 `0005_2FeetJump001` 本身有水平位移；压 XY 与数据冲突。→ 评测改看 `|z_err|`、yaw/pitch、多跳存活、jump vs stand。

**Q7：为何不用训练终点 ckpt？**  
A：SFU@5000、height@4200 均过拟合摔倒；中间点更好。→ **导出前必须 MuJoCo 扫点**（已固定 SFU3600 / height4000）。

**Q8：踝 Roll 训练 Kp=0，部署为何调到 3？**  
A：Isaac 匹配 Jul14；MuJoCo 落地俯仰更敏感。→ 部署 YAML 略硬 anklePitch/Roll，属 sim2sim 补偿，非改网络。

**Q9：导出脚本曾覆盖 Jul14 `policy_lstm_1.pt`？**  
A：导出共用临时名。→ 导出后从 `policy_lstm_jul14_teacher_ft_3000.pt` / `*_3600.pt` 恢复指针。

### 11.3 当前收敛结论

- 算法形态不变：**PPO + LSTM 残差跟踪**  
- 观测锁定：**82 维，未来 +5/+10**  
- 训练策略：**Teacher → SFU 稳落地 → height 短抬跳高**；每次短 FT 后扫 ckpt  
- 部署：`policy_lstm_sfu_height.pt`（4000）+ `adam_lite_jump_sfu_height.yaml`
